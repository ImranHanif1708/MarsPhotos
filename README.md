
# Mars Photos App
==================================

A simple Android app built with Kotlin that displays photos from Mars using a REST API. The app demonstrates modern Android development practices including Jetpack Compose, Retrofit, and Kotlin serialization.

## Features

- Fetches Mars photos from a remote API
- Displays photos in a grid layout
- Navigation between screens
- Error handling and loading states

## Tech Stack

- Kotlin
- Jetpack Compose
- Retrofit
- Kotlinx Serialization
- MVVM Architecture

## Getting Started

### Prerequisites

- Android Studio or IntelliJ IDEA 2025.1.3
- Android device or emulator
- JDK 17+

### Setup

1. Clone the repository:

   git clone
   https://github.com/ImranHanif1708/mars-photos-app.git

3. Open the project in Android Studio or IntelliJ IDEA.
4. Sync Gradle and build the project.
5. Run the app on an emulator or device.

## API

The app uses a REST API endpoint `/photos` to fetch Mars photos.
